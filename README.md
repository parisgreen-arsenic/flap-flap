Now I do know that Pygame does exist, but it simply did not run correctly on my computer so I switched over to Tkinter ( I know it isn't designed for complex games and is mostly used for User Interfaces) and out of boredom created this flappy bird clone.
The birds a triangle and the pipes are simply rectangles, it's not too complex, there are no sprites or anything complex objects only simple shapes.
The controls are:
"Space" or "UP Arrow" to go up.
"R" to restart.
"Esc" to quit the game.

Enjoy!
